CREMSON PAPER BUILDER
Final Developer Specification
Teacher-facing question-paper creation system
This document defines the required functionality, workflow, question-bank structure, generation rules and output format for the Cremson Paper Builder. The system should be built as a reusable question-paper engine. The first populated implementation will use CBSE Class XII Entrepreneurship, while the underlying structure must support additional classes, subjects and chapters later.
1. Product Objective
The Paper Builder should allow a teacher to select a paper pattern and generate a professional, printable question paper from Cremson's internally maintained and verified question bank. A teacher must be able to either generate questions automatically or select them manually, review individual questions, obtain an answer key and print/save the final paper.
The system is a question-paper builder, not an AI question generator.
The first implementation should be populated with Class XII Entrepreneurship.
The database architecture must not be hard-coded only for Entrepreneurship.
Only Approved + Active questions should normally be available for paper generation.

7. Case-Based Question Structure
A case-based item must be stored as a parent case with attached sub-questions:
Case/Passage
Sub-question 1 + marks + answer
Sub-question 2 + marks + answer
Sub-question 3 + marks + answer
Total marks
The passage must appear only once in the paper. The case passage and all its sub-questions must remain together during selection, replacement, numbering and printing.
8. Internal Choice
Support CBSE-style internal choices. An internal-choice pair should contain comparable questions with equal marks.
Example: Question 10 OR alternative Question 10.
The teacher should be able to add an internal choice where supported.
The two questions must remain associated during numbering and printing.
9. Duplicate Control and Validation
The same question must not appear twice in one paper.
The same case group must not appear twice in one paper.
The system should detect identical duplicate question text during question creation/import and warn the administrator.
Only Approved + Active questions should be available for generation.
If insufficient matching questions exist, display a clear message rather than selecting unsuitable questions.
Suggested message: "Not enough approved questions are available for this combination. Please reduce the requirement or change the filters."

The paper should remain suitable for black-and-white printing. Avoid unnecessary colour or visual decoration.
Avoid awkward page breaks where reasonably possible. A case passage should not be separated from its sub-questions, and internal-choice content should remain logically together.
13. Answer Key
Provide a separate Answer Key view/print output using the exact same question numbering.
Objective: correct option/answer.
Very Short / Short / Long: model answer and marking scheme.
Case-Based: answer and marks for each sub-question.
Internal choices: include the corresponding answers/marking schemes.
14. Generator Rules
Generated paper must equal the selected Maximum Marks.
No question may repeat in the same test.
Only Approved + Active questions may be generated.
Questions remain fixed until the teacher regenerates or replaces them.
Individual replacement should preserve Chapter, Question Type, Marks and approximate Difficulty.
Internal-choice questions must carry equal marks.
Case passage and sub-questions must remain together.
Question and section numbering must be automatic.
Answer Key numbering must exactly match the question paper.
Questions should be arranged section-wise, not randomly across sections.
If sufficient matching questions are unavailable, clearly notify the teacher.

16. Future-Ready Architecture
The first version should stay focused, but the underlying structure should allow later addition of features such as:
Saved papers / My Papers
Duplicate Paper / Set A, B, C
More classes and subjects
More advanced CBSE blueprints
Editable Word export
School logo/custom templates
Online student examinations
Automatic objective checking
Student results and analytics
Advanced competency/difficulty balancing
AI-assisted generation using the verified Cremson question bank
These are future extensions; they should not make the core Paper Builder workflow unnecessarily complex.
17. First Content / Pilot
The first populated question bank should be Class XII Entrepreneurship. The system should nevertheless use Class, Subject, Chapter and Topic as independent database fields so additional subjects can be added without rebuilding the engine.
18. Final Product Principle
The core product is not simply a random question generator. It is a structured paper-building system powered by Cremson's author-created, reviewed and verified question bank.
The intended experience is: Select what you want → Generate or Select → Review → Print.
The system should prioritise correctness, reliable question tagging, CBSE-style paper structure, easy teacher use and professional printable output.
